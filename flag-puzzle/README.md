# 조각조각 세계 여행 · 국기 퍼즐

`weekly-games/flag-puzzle/`에서 실행하는 정적 어린이 국기 퍼즐.

## 놀이 방법

1. 나라와 조각 수(4 / 6 / 12)를 고르고 시작합니다.
2. 조각을 빈칸으로 끌어 놓습니다. 조각과 빈칸을 차례로 누르거나 키보드 Enter/Space로 선택해도 됩니다.
3. 잘못된 위치에 놓으면 조각은 그대로 남습니다. 시간제한·실패 횟수·점수 벌점이 없습니다.
4. 밑그림을 켜거나 끌 수 있고, 도움 버튼은 한 조각을 맞춰 줍니다.
5. 완성 도장은 브라우저에 저장됩니다. 같은 나라의 난이도별 완성도 별도로 기록합니다.
6. 완성 후 다음 나라, 재도전, 세계 백과의 해당 나라로 이동할 수 있습니다.

기본 195개 나라를 모두 선택할 수 있습니다. 국기와 국가 정보는 `../world-atlas/data.js` 및 `../world-atlas/flags.js`를 공유합니다. 두 폴더를 같은 상위 폴더에 배포해야 합니다. 별도 빌드·외부 API·외부 이미지 요청은 없습니다.

## 조각 판정

정방향 직사각형 조각이며 회전시키지 않습니다. 원본 국기를 640×480 캔버스에 먼저 그린 후 각 조각의 픽셀을 샘플링합니다. 육안으로 구분하기 어려운 동일 패턴 조각은 같은 그룹으로 처리해 서로 교환해도 정답입니다. 조각 중복 사용이나 이미 맞춘 칸 덮어쓰기는 차단합니다.

## 소리와 저장

Web Audio로 짧은 조각·완성 효과음을 합성합니다. 나라 이름 읽기는 기기의 Web Speech 한국어 음성에 따릅니다. 음표 버튼으로 소리를 켜고 끕니다. localStorage가 제한된 경우 현재 놀이를 계속할 수 있지만 기록이 유지되지 않을 수 있습니다. 앱은 개인정보나 플레이 기록을 서버에 보내지 않습니다.

실제 iOS/iPadOS 터치·음성 출력은 기기 확인이 필요합니다. 390px iframe에서 반응형 배치를 검사했고, 데스크톱 브라우저에서 드래그·탭·키보드를 검사했습니다.
